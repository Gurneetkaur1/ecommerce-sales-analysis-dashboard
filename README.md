# E-Commerce Sales Analysis Dashboard

## Overview

This project analyzes 99K+ e-commerce orders using SQL and Power BI to understand sales performance and customer trends.

## Tools Used

* SQL
* Power BI

## Dashboard Analysis

* Monthly Revenue Trends
* Payment Type Analysis
* Top States by Orders
* Top Product Categories by Revenue
* Revenue, Orders, Customers & Freight Cost
* Interactive filters for Year, Month, State, Order Status, and Payment Type
